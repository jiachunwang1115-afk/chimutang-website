# 痴木堂经销商小程序

原生微信小程序，与 `woodall.design` 经销商报价网页共用产品目录，并为正式账号、总部报价同步预留同一套接口。

## 已完成

- 经销商账号登录与首次修改密码
- 明确的本机体验模式，云端未启用时仍可完整报价
- 业务首页、累计报价金额与最近项目
- 项目资料、最多 8 条产品明细、排序和自动保存
- 138 款产品搜索、四大系列筛选、真实产品缩略图与资料状态
- 净面积、损耗、辅材、安装、运输、其他费用、折扣和税额计算
- 报价校验、历史搜索、复制、删除和继续编辑
- 账号状态、总部电话及网页版 PPT / PDF 地址复制

## 开发者工具预览

1. 运行 `npm run build:miniprogram`，同步官网产品目录、Logo 和登录实景图。
2. 在微信开发者工具中导入 `dealer-miniprogram` 目录。
3. 开发版与体验版会预填受环境限制的演示账号，便于现场展示；正式发布版自动关闭该账号并仅接受总部账号。

## 正式提审前配置

1. 使用痴木堂公司主体注册并认证小程序。
2. 将正式 AppID 写入 `project.config.json`；AppSecret 只保存在服务端环境中，不进入代码仓库。
3. 接通总部账号数据库后，确保 `https://www.woodall.design/api/dealer` 返回 JSON 接口。
4. 在小程序后台将 `https://www.woodall.design` 配置为 request 合法域名。
5. 完成用户隐私保护指引，说明项目名称、地址和报价金额由经销商主动填写，并同步至痴木堂总部。
6. 使用微信开发者工具执行真机预览、体验版验收、上传和正式提审。

登录后的报价会保存在当前设备并同步至痴木堂总部账号数据库。
