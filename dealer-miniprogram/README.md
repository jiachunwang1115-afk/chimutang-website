# 痴木堂经销商小程序

原生微信小程序，和 `woodall.design` 经销商报价网页共用账号、报价数据库及产品目录。

## 当前页面

- 账号登录与首次修改密码
- 经销商业务首页
- 原生报价编辑与产品搜索
- 历史报价
- 我的账号

## 正式提审前配置

1. 使用痴木堂公司主体注册并认证小程序。
2. 将正式 AppID 写入 `project.config.json`，AppSecret 只保存在服务端环境中，不进入代码仓库。
3. 在小程序后台将 `https://www.woodall.design` 配置为 request 合法域名。
4. 完成用户隐私保护指引，说明项目名称、地址和报价金额由经销商主动填写，并同步至痴木堂总部。
5. 使用微信开发者工具执行真机预览、上传、体验版验收和正式提审。

运行 `npm run build:miniprogram` 会从官网产品库生成精简的小程序产品目录，并同步品牌 Logo 与登录背景图。
